# Reto técnico

La solución implementa dos servicios ejecutables y un ejercicio de arquitectura:

1. Traductor de endosos con Node.js, TypeScript, Hapi y PostgreSQL.
2. Servicio de rutas óptimas en Go utilizando Dijkstra.
3. Rediseño del proceso de préstamos para eliminar desembolsos duplicados y desacoplar la experiencia del cliente de la latencia de INARI.

Los componentes pueden levantarse localmente con Docker Compose y la infraestructura objetivo se define con Terraform sobre GCP.
